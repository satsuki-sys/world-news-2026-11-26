A one-image summary of the world's news of Thursday 26 November 2026,
entered in make.fun's [news-image-20261126](https://make.fun/c/news-image-20261126)
competition. The image is a newspaper front page: North Korea's Kim Jong Un
calling for tactical nuclear weapons to be spread wider leads, with
Ukraine's strike on a Russian air base and refineries, the US unveiling new
tariffs on 14 partners, Israeli judges urging that a Netanyahu bribery case
be dropped, and a round-up of the day's other stories.

`main.py` (Python 3.13, standard library only) copies the finished image
(`entry.png`, 1024×1024) to `/output/entry.png`. No network is used, and
both runs write the same bytes. `draw.py` draws the image with Pillow from
shapes and text only — no photographs — and is deterministic: run it twice
and the bytes match.
